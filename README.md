# Zaki Publisher Media

Public media output repository for Zaki Publisher.

- `render-jobs/` contains text-only render instructions.
- GitHub Actions renders PNG assets into `public/`.
- Only content intended for public social posting belongs here.
- No API tokens, passwords, or private files.

Public raw URL pattern:

`https://raw.githubusercontent.com/izak5891-tech/zaki-publisher-media/main/public/<path>.png`
